# DNA Sequence Classification Pipeline using K-Mer Topologies

## 🧬 Обзор проекта
Данный проект представляет собой сквозной биоинформатический пайплайн для автоматической классификации функциональных последовательностей ДНК. В качестве демонстрационной задачи реализовано бинарное разделение **промоторных участков** (GC-островки, инициирующие транскрипцию) и **некодирующих (интронных/мусорных) регионов** генома.

---

## 🏗️ Архитектура и Инженерные принципы

1. **Модульность (Separation of Concerns):** Тяжелая биоинформатическая логика вынесена из интерактивного ноутбука в отдельный Python-модуль `src/features.py`.
2. **Feature Engineering в биоинформатике:** Строковые генетические последовательности векторизуются с помощью метода **К-меров (K-mers)**. Строка разбивается на перекрывающиеся подпоследовательности длины K=3 (триплеты/кодоны). 
3. **Воспроизводимость (Reproducibility):** Все генераторы случайных чисел зафиксированы с помощью единого `random_seed=42`.

### Структура репозитория:
* `data/` — локальное хранилище геномных датасетов
* `src/features.py` — модуль расчета GC-состава и токенизации К-меров
* `dna_analysis.ipynb` — основной Jupyter-ноутбук (EDA, обучение, графики)
* `README.md` — документация проекта

## 🔬 Математический и Биологический базис

### 1. Расчет GC-состава (GC-Content)
GC-состав является ключевым физико-химическим маркером стабильности двойной спирали ДНК. Формула расчета:

\[GC\% = \frac{Count(G) + Count(C)}{Total(A + C + G + T)}\]

### 2. Токенизация ДНК через К-меры
Для строки ДНК длиной L количество извлекаемых K-меров вычисляется по формуле:

\[N = L - K + 1\]
